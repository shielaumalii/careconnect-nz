# CareConnect NZ

A Mini Health Information Exchange (HIE) built with Spring Boot and React.

## Tech Stack

- Java 21
- Spring Boot
- React
- TypeScript
- PostgreSQL
- Maven

## Features

- Patient Management
- Appointments
- Clinical Notes
- Laboratory Results
- Authentication
- REST API
